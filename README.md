# 🏃 10K Step Tracker

A simple Python program that tracks your daily steps and calculates how many days it takes to reach the **10,000-step goal**.

## ✨ Features

* Enter your steps for each day
* Keep track of total steps
* Calculate remaining steps
* Prevent negative step values
* Display a congratulations message when the goal is reached

## 🛠️ Built With

* Python 3

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/10k-Step-Tracker.git
```

Go to the project directory:

```bash
cd 10k-Step-Tracker
```

Run the program:

```bash
python main.py
```

## 💡 Example

```text
🏃 Welcome to the 10K Step Tracker!
🎯 Your daily goal: 10,000 steps

Enter your steps for today: 3000
📊 7,000 steps remaining to reach the goal.

Enter your steps for today: 4000
📊 3,000 steps remaining to reach the goal.

Enter your steps for today: 3500
🎉 Congratulations! You reached 10,000 steps after 3 day(s)!
```
